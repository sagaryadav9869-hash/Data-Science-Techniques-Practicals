# Data Science Techniques (DST) Practicals

Practical work in Data Science Techniques using Python and R: exploratory data analysis (EDA) and visualization on customer shopping and retail superstore datasets, time series stationarity and seasonal decomposition on energy consumption data, NumPy array operations and Pandas employee data wrangling, R programming fundamentals, and tidyverse data manipulation (`dplyr` and `tidyr`). Each practical includes code implementations, execution outputs/visualizations, and analysis.
